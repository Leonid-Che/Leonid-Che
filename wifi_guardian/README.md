# Wi-Fi Guardian (Демонстрационный проект)

Android-приложение, которое **по команде пользователя** сканирует список доступных
Wi-Fi сетей и позволяет выбрать любую из них, чтобы:

1. Посмотреть её параметры (BSSID, канал, уровень сигнала, шифрование);
2. Управлять подключением **собственного устройства** к этой сети
   (подключиться / отключиться);
3. Оценить, есть ли у вас легальные технические возможности повлиять на
   подключение **других** устройств к выбранной сети (роутер в вашей сети —
   да; чужая сеть — нет).

---

## ⚠️ Правовой дисклеймер (обязательно к прочтению)

Проект предназначен **только для обучения, исследований собственной сети и
аудита безопасности с письменного разрешения владельца сети**.

Вмешательство в работу Wi-Fi сетей и отключение **чужих** устройств
(deauth-флуд, рассинхронизация сессий, глушение радиоканала) в большинстве
стран является уголовным или административным правонарушением
(в РФ — ст. 272/273/274 УК РФ, ст. 13.7 КоАП РФ; в ЕС/США — Computer Fraud
and Abuse Act, Directive 2013/40/EU и аналоги).

Это приложение **не содержит и не будет содержать** функций деаутентификации,
глушения или иного воздействия на сторонние сети и устройства.

---

## Что технически возможно с Android-смартфона

| Сценарий | Возможно? | Как |
|---|---|---|
| Сканировать список сетей вокруг | ✅ Да | `WifiManager.startScan()` / `getScanResults()` (с геолокационными разрешениями) |
| Подключать/отключать **своё** устройство к выбранной сети | ✅ Да | `WifiNetworkSuggestion` / `WifiManager.disconnect()` (Android 10+) |
| Запрещать подключение других устройств к **своему** роутеру | ✅ Да | Через API/веб-интерфейс роутера: MAC-фильтрация, «детский контроль», лимит клиентов, kick-сессии (например, API OpenWrt/uCI, TP-Link Omada, Keenetic) |
| Отключать другие устройства от **чужой** сети | ❌ Нет и незаконно | Требует deauth-атак — см. дисклеймер выше |

Именно поэтому «выбор сети из списка» в приложении ведёт либо к управлению
своим подключением, либо (если сеть помечена как «моя») открывает инструкции
по настройке родительского роутера.

## Требования для сборки

* Android Studio (Giraffe+), JDK 17
* `compileSdk = 34`, `minSdk = 29` (используются только современные Wi-Fi API)
* Физическое устройство (эмулятор плохо работает с реальным Wi-Fi-сканом)

## Разрешения в манифесте

```xml
<uses-permission android:name="android.permission.ACCESS_WIFI_STATE"/>
<uses-permission android:name="android.permission.CHANGE_WIFI_STATE"/>
<uses-permission android:name="android.permission.NEARBY_WIFI_DEVICES"
                 android:usesPermissionFlags="neverForLocation"/> <!-- Android 13+ -->
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/> <!-- Android 12 и ниже -->
```

## Структура проекта

```
wifi_guardian/
├── README.md
└── app/src/main/java/com/example/wifiguardian/
    ├── MainActivity.kt          # UI: список сетей + панель управления
    ├── WifiScanner.kt           # скан сетей, дедупликация по BSSID
    └── MyNetworkController.kt   # подключение/отключение СВОЕГО устройства
```

Файлы исходников лежат в `app/src/main/java/com/example/wifiguardian/`.
Чтобы получить полноценный проект, создайте пустой проект «Empty Views Activity»
(Kotlin) в Android Studio, скопируйте туда папку `app/` и добавьте зависимости
(AndroidX lifecycle-coroutines, material).

## Как это работает (кратко)

1. `MainActivity` при запуске запрашивает разрешения и запускает
   `WifiScanner.scan()`.
2. Результаты скана группируются по SSID/BSSID и показываются в RecyclerView
   с уровнем сигнала и типом шифрования.
3. Тап по сети открывает панель:
   * **«Подключить это устройство»** — добавляет `WifiNetworkSuggestion`
     (пароль запрашивается в диалоге) и включает Wi-Fi;
   * **«Отключить это устройство»** — `wifiManager.disconnect()` + удаление
     suggestion'а;
   * **«Это мой роутер»** — показывает чек-лист легальных способов ограничить
     подключение других устройств (MAC-фильтр, лимит клиентов и т.п.).
4. Для чужих сетей панель ограничения других устройств **намеренно недоступна**
   и показывает правовую справку.

## Идеи для развития (легальные)

* Интеграция с API домашнего роутера (Keenetic REST API, OpenWrt RPC/UCI):
  кнопка «заблокировать клиент X в моей сети» вызывала бы MAC-бан на роутере.
* Лог событий подключения/отключения собственного устройства.
* Виджет быстрых команд («Интернет-режим», «Только моя сеть»).
