TabletTouch / Windows Cursor Control — предпросмотр проекта

Слева — окно сервера на Windows 10 (pc_server/main.py). Справа — планшет Android 12 (android_app): принимает видеопоток H.264 с пропорциональной подгонкой (чёрные поля) и управляет курсором ПК касаниями. Всё интерактивно.

Как устроен проект

pc_server/ — mss захват → PyAV libx264/nvenc (H.264 annex-b) → WebSocket :8765; приём тачей → SendInput (input_inject.py); смена ориентации → ChangeDisplaySettingsExW/DDC-CI или программный доворот кадра.
android_app/ — MediaCodec-декодер + SurfaceView (aspect-fit = та же пропорциональная подгонка), MotionEvent → JSON-команды hello / orientation / touch. Wi-Fi и USB (adb forward tcp:8765) — одним стеком.

Касайтесь экрана планшета — курсор Windows перемещается в соответствующую точку (абсолютный режим). Долгое нажатие >0.65 с = правый клик. Кнопки ниже эмулируют гироскоп: портретная ориентация планшета разворачивает изображение ПК.
