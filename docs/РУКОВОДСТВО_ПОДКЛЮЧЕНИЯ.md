## 1. Что понадобится

| Компонент | Требование |
|---|---|
| Компьютер | Windows 10. Вариант 1 (без Python): готовый `TouchCursorServer.exe` (см. п. 2.0). Вариант 2 (из исходников): Python 3.8+; для Bluetooth — ещё pyserial; для USB — pyusb + libusb-драйвер |
| Смартфон | Android 10 или выше, приложение TouchCursor (папка `android/`) |
| Кабель (для USB) | Исправный USB-кабель с передачей данных |
| Адаптеры (для BT) | Bluetooth на смартфоне и на ПК (можно USB-«свисток») |

Структура проекта:
* `windows_server/` — Python-сервер для Windows (порт по умолчанию **5575**);
* `android/` — исходники Android-приложения (открывать в Android Studio).

## 2. Часть A. Установка сервера на компьютер

### 2.0. Готовый EXE (без установки Python)

Сервер распространяется одним файлом **`TouchCursorServer.exe`** — на компьютере
не нужно устанавливать Python. Просто скопируйте EXE в любую папку и запустите
двойным щелчком (Wi-Fi-режим) либо из командной строки:

```bat
TouchCursorServer.exe              REM Wi-Fi (TCP, порт 5575)
TouchCursorServer.exe --port 5575  REM другой порт
TouchCursorServer.exe --usb        REM USB/AOA (нужна сборка TouchCursorServer-USB.exe)
TouchCursorServer.exe --bt COM5    REM Bluetooth (нужна сборка TouchCursorServer-BT.exe)
```

При первом запуске по Wi-Fi брандмауэр спросит, разрешить ли программе принимать
соединения, — нажмите «Разрешить доступ» (или откройте порт вручную, см. п. 2.3).
Окно консоли держите открытым всё время работы; закрыть его можно через Ctrl+C
или просто крестиком.

**Как собрать EXE самостоятельно** (если готового файла нет), на машине с Python 3.9+:

```bat
cd C:\path\to\TouchCursor\windows_server
build_exe.bat          REM -> dist\TouchCursorServer.exe (Wi-Fi)
build_exe_bt.bat       REM -> dist\TouchCursorServer-BT.exe (+ pyserial)
build_exe_usb.bat      REM -> dist\TouchCursorServer-USB.exe (+ pyusb, libusb-1.0.dll)
```

Скрипты сами ставят PyInstaller и собирают однофайловый EXE. Для USB-сборки
положите `libusb-1.0.dll` (64-bit, из libusb.github.io) в каталог сборки рядом
с `python.exe` или в `dist\` после сборки.

### 2.1. Запуск из исходников (альтернатива EXE)

1. Установите Python 3.8+ с [python.org](https://www.python.org/downloads/)
   (при установке отметьте галочку **«Add Python to PATH»**).
2. Откройте командную строку (cmd) и перейдите в папку сервера:
   ```bat
   cd C:\path\to\TouchCursor\windows_server
   ```
3. Установите зависимости:
   ```bat
   pip install -r requirements.txt
   ```
   * Для режима **Wi-Fi** зависимостей нет вовсе (можно сразу запускать пункт 4).
   * Для режима **Bluetooth** дополнительно: `pip install pyserial`.
   * Для режима **USB** дополнительно: `pip install pyusb` (драйвер ставится один раз через Zadig — см. п. 5.1).
4. Запустите сервер в нужном режиме:
   ```bat
   python -m touchcursor_server            REM Wi-Fi (TCP, порт 5575)
   python -m touchcursor_server --port 5575
   python -m touchcursor_server --usb      REM USB (AOA)
   python -m touchcursor_server --bt COM5  REM Bluetooth (COM-порт)
   ```
   В режиме Wi-Fi сервер печатает IP-адрес компьютера в локальной сети — запишите его
   (понадобится при вводе адреса в приложении). Окно с сервером держите открытым всё время работы.
5. **Брандмауэр Windows.** При первом запуске по Wi-Fi разрешите Python (или EXE) принимать входящие
   соединения (в диалоге брандмауэра — «Разрешить доступ»), либо откройте порт вручную
   (командная строка от администратора):
   ```bat
   netsh advfirewall firewall add rule name="TouchCursor" dir=in action=allow protocol=TCP localport=5575
   ```

> Совет: команды запуска из пунктов 2.0 и 2.1 взаимозаменяемы — вместо `python -m touchcursor_server`
> в примерах ниже можно использовать `TouchCursorServer.exe` (и `-BT`/`-USB`-сборки для соответствующих каналов).

## 3. Способы подключения смартфона к компьютеру

Приложение поддерживает три канала связи. На нижней панели экрана расположены кнопки выбора
канала: **«Wi-Fi»**, **«USB»**, **«Bluetooth»** — активный канал подсвечивается зелёным.
Канал можно переключить в любой момент; приложение переподключится автоматически.

---

## 4. Вариант 1. Wi-Fi (по локальной сети)

Самый простой способ: телефон и компьютер должны быть в **одной сети Wi-Fi**.

1. На компьютере запустите сервер без параметров:
   ```bat
   python -m touchcursor_server
   ```
   В консоли появятся строки вида `IP в локальной сети: 192.168.1.47` — это адрес компьютера.
   (Тот же адрес можно узнать командой `ipconfig` в разделе беспроводного адаптера.)
2. В приложении на телефоне кнопкой **«Wi-Fi»** выберите этот канал.
3. В поле адреса вверху экрана введите IP компьютера, например `192.168.1.47`.
   Порт менять не нужно — используется 5575 (если сервер запущен с другим портом — укажите его).
4. Нажмите служебную кнопку активации управления внизу экрана — статус сменится на «Подключено».

## 5. Вариант 2. USB-кабель

Телефон подключается кабелем и работает как Android Accessory (протокол AOA).
Не нужны ни сеть, ни Bluetooth; связь стабильная и без задержек.

### 5.1. Подготовка (выполняется один раз)

1. На телефоне включите **отладку по USB**:
   Настройки → О телефоне → 7 раз нажмите «Номер сборки» → вернитесь в настройки:
   Система → Для разработчиков → Отладка по USB → **Вкл**.
2. Подключите телефон кабелем к ПК и в уведомлении телефона выберите режим
   **«Передача файлов» (MTP)** — не «Только зарядка».
3. На компьютере установите драйвер libusb для аксессуара:
   * скачайте [Zadig](https://zadig.akeo.ie/) и запустите от администратора;
   * в меню выберите **Options → List All Devices**;
   * в списке найдите устройство TouchCursor / Android Accessory
     (идентификаторы **VID 18D1, PID 2D70**). Оно появляется только после того, как
     приложение на телефоне хотя бы раз активировало USB-режим (см. п. 5.2, шаг 2);
   * нажмите **Install Driver** (процесс занимает 1–2 минуты).

### 5.2. Ежедневное подключение

1. Запустите сервер:
   ```bat
   python -m touchcursor_server --usb
   ```
   Если написано «AOA-устройство TouchCursor не найдено» — выполните шаг 2 и запустите сервер снова.
2. В приложении на телефоне нажмите кнопку **«USB»**, затем служебную кнопку активации управления.
   Телефон перейдёт в режим аксессуара AOA; при первом таком переходе Windows предложит
   установить драйвер — см. п. 5.1, шаг 3.
3. Статус в приложении станет «Подключено», а сервер выведет
   `USB-канал открыт: USB (AOA 18d1:2d70)`.

> Примечание: пока активно управление, телефон заряжается от порта USB, но обычное определение
> как накопителя (MTP) приостанавливается. Для возврата отключите управление кнопкой в
> приложении и переподключите кабель.

## 6. Вариант 3. Bluetooth

Используется профиль SPP (RFCOMM). Удобно, когда нет общей Wi-Fi сети и под рукой нет кабеля.

### 6.1. Сопряжение (выполняется один раз)

1. На компьютере: Параметры → Устройства → Bluetooth → включите Bluetooth →
   **«Добавление Bluetooth или другого устройства»** → Bluetooth.
2. На телефоне включите Bluetooth (Настройки → Подключённые устройства) и сделайте
   себя обнаруживаемым.
3. Дождитесь появления телефона в списке на ПК → нажмите на него → **Сопряжение/Подключение**.
4. Подтвердите совпадение кода на обоих устройствах.
5. Узнайте номер виртуального **исходящего** COM-порта, который создал Windows:
   * Панель управления → «Устройства и принтеры» → правый щелчок по значку телефона →
     Свойства → вкладка **«Ports (COM & LPT)»** → запишите номер, например `COM5`.
   * Там же на вкладке «Services» убедитесь, что включён пункт «Доступ к исходящим портам»
     (Outgoing ports).

### 6.2. Ежедневное подключение

1. Запустите сервер с номером порта из п. 6.1, шаг 5:
   ```bat
   python -m touchcursor_server --bt COM5
   ```
2. В приложении на телефоне нажмите кнопку **«Bluetooth»**.
   * При первом выборе приложение запросит разрешение **BLUETOOTH_CONNECT** — согласитесь.
   * Поле адреса можно оставить пустым (автовыбор сопряжённого адаптера ПК) или ввести
     MAC-адрес компьютера (Параметры → Bluetooth и другие устройства → Дополнительные свойства → Address).
3. Нажмите служебную кнопку активации управления — приложение установит RFCOMM-соединение с ПК.
4. Статус станет «Подключено»; сервер выведет `Bluetooth-канал открыт: COM5`.

> Если Windows спросит разрешение на соединение с устройства («Разрешить…»), ответьте «Разрешить».

## 7. Сборка и установка приложения на смартфон

### Вариант А — сборка в Android Studio (рекомендуется)

1. Установите [Android Studio](https://developer.android.com/studio).
2. **Важно: путь к проекту должен содержать только латиницу, цифры и дефисы**
   (например, `C:\Users\<user>\AndroidStudioProjects\TouchCursor`).
   Если в пути есть кириллица, пробелы или спецсимволы, Gradle выдаёт предупреждение
   *«Your project path contains non-ASCII characters…»* — подробнее см. п. 7.1 ниже.
3. **File → Open…** → выберите папку `android/` проекта → дождитесь завершения Gradle Sync.
4. Подключите телефон по USB и разрешите отладку (см. п. 5.1, шаг 1), либо используйте эмулятор.
5. Нажмите **Run ▶** — приложение соберётся и установится на устройство.

### 7.1 Предупреждение «non-ASCII characters» при сборке

Gradle-плагины Android не гарантируют корректную работу, если полный путь к проекту
(или к папке `.gradle`/`Android SDK`) содержит символы вне ASCII — например, русские
имена пользовательских папок (`C:\Пользователи\Иван\…`). Это может привести к ошибкам
сборки NDK/AAPT на Windows.

**Основное решение** — переместить проект в каталог с «английским» путём:

```
C:\AndroidProjects\TouchCursor\android
```

(Файл → Закрыть проект → перенести папку → File → Open… заново.)

Если перемещение невозможно, проверка отключается строкой в `gradle.properties`
в корне проекта. **Это уже сделано в поставляемом проекте** (`android/gradle.properties`):

```properties
android.overridePathCheck=true
```

Предупреждение исчезнет, но учтите: флаг лишь подавляет проверку. Если сборка
всё же упадёт с ошибками AAPT2/NDK («illegal character», «Cannot create resource
output directory», кракозябры в путях лога), перенос проекта в ASCII-каталог
обязателен. Дополнительно убедитесь, что:

* путь к Android SDK и папка `LOCALAPPDATA\Google\AndroidSdk…` не содержат кириллицы;
* переменные окружения `ANDROID_HOME` / `ANDROID_SDK_ROOT` указывают на ASCII-путь;
* после переноса выполните **File → Invalidate Caches / Restart** и повторную Gradle Sync.

### Вариант Б — готовый APK

Если APK уже собран (`android/app/build/outputs/apk/debug/app-debug.apk`):
1. Скопируйте файл на телефон (кабель, облако и т. п.).
2. Откройте файл на телефоне → разрешите установку из неизвестных источников → **Установить**.

## 8. Запуск приложения и порядок работы

1. **Запустите сервер на компьютере** в нужном режиме (раздел 2, п. 4).
2. **Выберите канал связи** на нижней панели приложения: «Wi-Fi», «USB» или «Bluetooth»
   (активный подсвечен зелёным).
   * Wi-Fi — заполните поле адреса вверху экрана (IP компьютера).
   * Bluetooth — при первом выборе подтвердите запрос разрешения.
3. **Нажмите служебную кнопку активации управления** внизу экрана
   (надпись «Управление: ВЫКЛ (нажмите, чтобы включить)»).
   * Приложение попросит разрешить показ уведомлений — согласитесь; стартует фоновая служба
     и устанавливается соединение. Кнопка изменит надпись на «Управление: ВКЛ …»,
     а статус вверху сменится на «Подключено».
   * Пока кнопка включена, **кнопки громкости телефона не изменяют громкость** — они управляют мышью.
4. Работайте тачпадом (центральная зона экрана) и кнопками телефона (см. раздел 9).
5. По окончании **нажмите служебную кнопку ещё раз** (переведите в «ВЫКЛ») — регулировка
   громкости восстановится, курсор освободится. Сервер на компьютере останавливается
   в консоли сочетанием `Ctrl+C` (или закрытием окна EXE).

Автосоединение: если связь пропала (выдернут кабель, телефон ушёл из сети), приложение
пытается переподключиться каждые 2 секунды, пока кнопка активации включена.

## 9. Управление: кнопки и жесты

| Действие | Результат на ПК |
|---|---|
| Палец по тачпаду | Перемещение курсора (абсолютное позиционирование) |
| Тап одним пальцем по тачпаду | Клик ЛКМ |
| Два пальца вверх/вниз по тачпаду | Прокрутка колеса мыши |
| Кнопка **«Громкость+»** (одиночное нажатие) | Одиночный клик ЛКМ |
| Кнопка **«Громкость+»** (двойное нажатие) | Двойной клик ЛКМ |
| Кнопка **«Громкость−»** (короткое нажатие) | Клик ПКМ |
| Кнопка **«Громкость−»** (удержание) | Зажать ПКМ (перетаскивание); отпускание — отжать |
| Кнопка **«−»** на нижней панели | Уменьшить скорость перемещения курсора (уровни 1…10) |
| Кнопка **«+»** на нижней панели | Увеличить скорость перемещения курсора (уровни 1…10) |
| Индикатор между «−» и «+» | Текущий уровень скорости (по умолчанию 5) |
| Кнопки **«Wi-Fi» / «USB» / «Bluetooth»** | Выбор канала подключения |
| Кнопка **«?»** справа | Краткая встроенная справка |
| Служебная кнопка внизу | Вкл/выкл режима управления |

## 10. Решение типовых проблем

**Не подключается по Wi-Fi (статус «Ожидание…» / «Нет соединения»)**
* Телефон и ПК в одной Wi-Fi сети?
* Правильный ли IP введён? Сервер печатает его при запуске; проверьте также `ipconfig` на ПК.
* Брандмауэр блокирует Python? Выполните команду `netsh ...` из раздела 2, п. 5.
* Домашнюю сеть переведите в профиль «Частные»: Параметры → Сеть и Интернет →
  Wi-Fi/Ethernet → Тип профиля сети.

**USB: «AOA-устройство TouchCursor не найдено»**
* Управление в приложении должно быть включено (кнопка «USB» + активация) — только тогда
  телефон переходит в режим аксессуара. После этого перезапустите сервер с `--usb`.
* Режим USB на телефоне — «Передача файлов», не «Только зарядка».
* Не установлен libusb-драйвер — выполните установку через Zadig (п. 5.1, шаг 3).
* Попробуйте другой кабель/порт (желательно напрямую в материнскую плату).

**Bluetooth: не находится COM-порт / нет соединения**
* Устройство должно быть **сопряжено**, а не просто обнаружено (раздел 6.1).
* Используйте именно **исходящий** (Outgoing) порт с вкладки Ports.
* Сервер (`--bt COM…`) должен быть запущен **до** нажатия кнопки активации на телефоне.
* Windows может спросить разрешение на входящее RFCOMM-соединение — ответьте «Разрешить».

**Кнопки громкости не работают как кнопки мыши**
* Служебная кнопка должна быть в положении «вкл» — только тогда приложение перехватывает их.

**Курсор двигается слишком медленно/быстро или рывками**
* Измените уровень скорости кнопками «−/+» (1 — минимальная, 10 — максимальная).
* Для максимальной отзывчивости используйте USB; в Wi-Fi — сеть 5 ГГц со устойчивым сигналом.

**Нужна подсказка прямо на телефоне**
* Нажмите кнопку **«?»** на нижней панели — откроется встроенная краткая справка.
